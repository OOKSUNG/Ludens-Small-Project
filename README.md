# Ludens-Small-Project

Ludens 2025-1 Small project

### TEAM UP!

2D cooperative multiplayer platformer game developed with Unity and Photon Pun2.

Small project from the Ludens game development club (2025-1).

Team Size: 3

## Project Overview

TEAM UP! is a 2D multiplayer cooperative puzzle platformer game where two players must work together to solve puzzles and clear stages.

The project focuses on real-time multiplayer synchronization, cooperative gameplay mechanics, and stage-based puzzle progression. :contentReference[oaicite:0]{index=0}

## Tech Stack

- Unity
- C#
- Photon Pun2

## Features

### Multiplayer System
- Real-time multiplayer synchronization using Photon Pun2
- Player spawning and room management
- Nickname synchronization
- Network-based stage progression

### Cooperative Gameplay
- Two-player cooperative puzzle gameplay
- Stage-based progression system
- Cooperative stage clear conditions

### Stage System
- Multiple stages with progression
- Portal/checkpoint-based stage transition
- Score and coin collection system

### Gameplay System
- Player movement and jumping
- Enemy collision and respawn system
- Animation synchronization
- Shared stage state synchronization

### Trap & Puzzle System
- Various traps and puzzle mechanics
- Cooperative interaction elements
- Platform-based puzzle design
